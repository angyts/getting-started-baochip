# I²C — a two-wire peripheral bus

**In one sentence:** I²C lets the Baochip communicate with multiple relatively low-speed chips using a shared clock line and a shared data line.

## The two signals

- **SCL** is the serial clock.
- **SDA** is the serial data.

Devices share the bus. Each device has an address, and the controller uses that address to select which device should respond.

Typical uses include sensors, power-management chips, small displays, clock chips and configuration memories.

## What the Baochip documentation provides

The register-reference index lists four uDMA I²C controller instances:
- [I²C0](https://ci.betrusted.io/bao1x/udma_i2c_0.html)
- [I²C1](https://ci.betrusted.io/bao1x/udma_i2c_1.html)
- [I²C2](https://ci.betrusted.io/bao1x/udma_i2c_2.html)
- [I²C3](https://ci.betrusted.io/bao1x/udma_i2c_3.html)

The IO configuration chapter and hardware pinout identify alternate-function pins for I²C. For example, PB11/PB12 provide I²C_SCL_B[0]/I²C_SDA_B[0]. There are other I²C options on other ports.

The autogenerated register pages are the correct place to inspect the controller's exact registers and bit fields. The book's introduction lists I²C as a topic for future supplemental driver documentation, so it does not provide a complete application-level programming guide.

## What to check when wiring an I²C component

1. Confirm the chip's supply voltage and logic voltage.
2. Confirm which pin pair is routed to the chosen I²C controller instance.
3. Confirm that SCL and SDA have suitable pull-ups to the correct logic rail.
4. Confirm the peripheral's 7-bit or 10-bit address convention.
5. Use a driver that handles acknowledgements, NACKs, timeouts and bus recovery.

A detected address only proves that something acknowledged a bus transaction. It does not prove the device's sensors, outputs or operating modes are configured correctly.

## Xous example from the project

The Dabao I²C client/service code is in:
- [bao1x HAL I²C driver](https://github.com/betrusted-io/xous-core/tree/main/libs/bao1x-hal/src)
