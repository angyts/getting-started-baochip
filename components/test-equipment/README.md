# PEOPLE RE-YB1006 multimeter

Photo shows actual meter with three jacks: mA, COM, V/ohm/continuity (box art shows four; trust actual unit and manual, not generic artwork). Exact manual, fuse and calibration not verified. Restrict to low-voltage USB electronics. Black lead COM, red V/ohm for continuity/resistance/voltage. Install batteries as instructed.

Continuity: unplug all power, select diode/buzzer position near upper-left dial, touch probes together to confirm beep. Test intended net and adjacent nets. Resistance: 200 ohm initially for low resistance, measure probe resistance first; never measure powered circuit. Voltage: select white DC V 20 range at right, black on verified ground and red on test point, expect nominal rail only when powered. Avoid slipping across adjacent pins. Current: meter in series, not across power; verify actual fused input/range and maximum rating first, preferably use USB current meter for total draw. Return red lead to voltage jack afterward. Ordinary DMM cannot establish fast peak sag, I2S timing or class-D RMS output; use scope/logic analyzer and appropriate differential instrumentation. No mains measurements with this unverified meter.
